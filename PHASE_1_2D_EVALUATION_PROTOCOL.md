## 1. Objective & Scope Preservation

This report formalizes a reproducible **Dual-Evaluation Protocol** for the Masoud Nickparvar Brain Tumor MRI dataset while strictly preserving the underlying filesystem in `data/raw/` untouched:

1. **Original Dataset Preservation:** `data/raw/` remains completely unmodified (0 files deleted, moved, or altered; original 5,712 Training and 1,311 Testing structure intact).
2. **Benchmark Comparability (Protocol 1):** The original 1,311-image test set is retained for direct benchmark performance evaluation against existing published literature.
3. **Leakage-Controlled Evaluation (Protocol 2):** A deterministic, image-level deduplicated evaluation set (1,208 images) is defined via manifest filtering, eliminating all 103 test-set images whose SHA-256 byte hashes match training set images.

## 3. Deterministic Evaluation Manifest (Step 3)

The evaluation protocol is governed by a machine-readable CSV manifest generated by `src/data/evaluation_protocol.py`:

* **Manifest Location:** [evaluation_manifest.csv](file:///c:/Users/Harsh/Documents/sem%201/AI%20lab/MRI%20classification/artifacts/reports/evaluation_manifest.csv)
* **Manifest Schema:**
  - `file_path`: Relative POSIX path from `data/raw/` (e.g., `Testing/notumor/Te-no_0010.jpg`).
  - `sha256_hash`: 64-character hexadecimal SHA-256 byte digest.
  - `original_split`: `Training` or `Testing`.
  - `class_label`: `glioma`, `meningioma`, `notumor`, `pituitary`.
  - `in_raw_benchmark`: `True` for all 7,023 files.
  - `in_filtered_train`: `True` for all 5,712 training files.
  - `in_filtered_test`: `True` for 1,208 leak-free test files; `False` for the 103 cross-split duplicates.
  - `exclusion_reason`: `NONE` or `CROSS_SPLIT_EXACT_DUPLICATE_OF_TRAINING_SAMPLE`.

## 5. Scientific Disclaimer & Limitations (Step 6)

* **Image-Level vs. Patient-Level Validation:** The exclusion of 103 exact byte-duplicate test images guarantees zero *exact file identity* data contamination. However, because raw Kaggle JPEGs omit DICOM headers and patient IDs, slice-level variants from the same subject cannot be detected. Therefore, Protocol 2 is strictly defined as an **image-level byte-deduplicated evaluation**, not a patient-level or clinical validation.
